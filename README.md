# 🎵 Music Player App

This video is about **how the Music Player works**.

## 🔧 Functions This App Can Perform:

1. ▶️ **Play** – Start or resume audio playback.  
2. ⏸️ **Pause** – Temporarily stop the audio without resetting.  
3. 🔁 **Reset** – Restart the current track from the beginning.  
4. ⏮️ **Previous** – Go to the previous track in the playlist.  
5. ⏭️ **Next** – Skip to the next track in the playlist.  
6. ⏩ **Custom Speed Control** – Speed up or slow down playback using the **Speed Bar**.
